## Mapping Boundary

This is not a raw USS canon export. The mappings are public translation aids, not complete equivalence claims, internal specification disclosures, implementation claims, or grants of authority.

In public architecture documentation, the preferred operating language is structured meaning, semantic runtime, semantic engine, semantic core, semantic control, orchestration, bounded execution context, review boundary, authority boundary, trace, handoff artifact, and runtime governance rule. Internal terms appear in this file only to identify lineage and translation direction.
